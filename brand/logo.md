# VanSpace logo — spacebar concept

## Idea

**`van` + [spacebar] + `.dev`**

The domain is `vanspace.dev`. The logo makes the **space** literal: a keyboard **space bar** between `van` and `.dev`.

```text
van  ┌─────────────────┐  .dev
     │     space       │
     └─────────────────┘
```

Reads as:
- **vanspace.dev** (the URL)
- **Van Space** (Vancouver + Space Centre)
- **spacebar** (builder / keyboard culture)

Monochrome: ink `#1A1A1A`, cream key `#F4F0E8`, mist label `#8B8499`. Mono type (Plex Mono / system mono).

---

## Usage rules

| Do | Don’t |
| --- | --- |
| Keep the key wider than tall (real spacebar proportions) | Squash into a square wordmark without the mark file |
| Label the key `space` in mist, small tracking | Put sponsor logos on the key |
| Use mono / technical type for `van` and `.dev` | Script fonts or rocket clipart |
| Clear space ≈ half key height around lockup | Stretch the SVG |

### Minimum sizes
- Wordmark: ≥ 120px wide digital  
- Mark alone: ≥ 24px  

### On stickers / site
**Marketing hero:** wordmark **centered** (primary focal point). Optional particle/saucer field behind.  
Hero can animate the key: idle → slight press (1–2px down) on hover. Reduced-motion: static.
