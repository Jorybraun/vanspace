## Codechella prospectus — what “good” looks like (5 pages)

| # | Page | Job | VanSpace equivalent |
| --- | --- | --- | --- |
| 1 | **Cover** | Full-bleed **place illustration** + event name + city/date. Almost no sell copy. | Science World / dome sketch (or saucer art) + **VanSpace** + date + “Sponsor prospectus” |
| 2 | **Proof / track record** | “Dear sponsors” + **photos of past rooms** with short captions (we ran X, Y people showed). | Photos from your prior nights / community (or soft “building the room” if thin) — **credibility before ask** |
| 3 | **Who + what we need** | Clear **audience** + plain list of **what partners provide** (cash, tools, swag). Hiring angle optional. | Builders who ship · weekday PD · Kent/Wes gravity · cash / table / stage / bag insert |
| 4 | **Marketing you don’t do alone** | Show **how the room fills** (zine, tour, merch placement). Physical + digital. | Luma + LinkedIn/X + community intros (Nolan/Toki) + optional print — **one page, concrete** |
| 5 | **Package matrix + spend list + contact** | Simple **Tier table** (checks), short “money goes to…”, email. Negotiable note. | Platinum→Bronze matrix · no agenda · funds: venue, food, AV/stream, talent travel, swag |

### Design rules stolen from Codechella (not VancouverMade lime)

- **Calm cream / warm paper**, navy type, orange checks — not neon hackathon  
- **One hero drawing** on cover (landmark = lore)  
- **Lots of air** — short paragraphs, not walls  
- **Photos prove the community** before the spreadsheet  
- **One matrix page** ends the sell — don’t re-explain location 4×  
- **Merch as product** (cap/jacket placement) = our **swag bag insert rights**  
- **No session schedule** in the prospectus  

### What we do *not* copy blindly

- Hackathon-only benefits (prize slots, build-day tool credits) unless true for VanSpace  
- Workshops (deferred for v1)  
- Tier prices — theirs are hackathon-scale; ours stay keynote micro-con ($10k / $6k / $3k / $1.25k)

## Swag: attendee bag vs sponsor rights

### A. Event bag (everyone — VanSpace pays or Platinum underwrites)

| Item | Notes |
| --- | --- |
| Badge + lanyard | Ops |
| VanSpace sticker pack | Brand |
| Hero item (pick one) | Tee **or** notebook — monochrome |
| **Sponsor inserts** | By tier (below) — physical, not just digital |

### B. What **sponsors put in the bag** (sell this hard)

| Tier | In the bag |
| --- | --- |
| **Platinum** | Up to **3** items: e.g. stickers + sticker sheet + small product sample **or** credit card + one soft good; **logo on bag card** (“Supported by”); optional co-brand pin if they pay production |
| **Gold** | Up to **2** items: stickers + one sample / pamphlet / discount card |
| **Silver** | **1** item: sticker **or** card |
| **Bronze** | Logo on shared “thanks” card only (no bulk junk) |

**Rules (so the bag stays good):**

- You **approve** every insert (size, weight, no liquids that die at security if speakers travel).  
- No six-logo collage on the hero tee.  
- Sponsors **ship inserts by T−14** or lose the slot (cost still due).  
- Optional **paid upgrade:** “Hero co-brand” tee run — sponsor pays apparel delta.

### C. On-site engagement (v1 — no workshops)

Sell as **products**, not as agenda lines:

- Table / activation all day  
- Stage moment by tier (talk, demo, or fireside **inside** the main track)  
- Optional mentors on floor (if sponsor staffs it)  

**Explicitly not selling yet:** standalone workshops, breakout tracks, multi-room product training. Revisit only after the single-track day is locked and staffed.
