## Hard expectations

| Area | Requirement |
| --- | --- |
| **Speaker diversity** | He will **not** speak if the rest of the lineup is only people who look like him (well-represented white men). Diversify. |
| **Lineup position** | Prefers **keynote** or **early** slot. We already have him as **opening** — good. |
| **Honorarium** | Expects compensation when organizers are making money. May waive for tight community budgets — **talk to him**. |
| **Always covered** | **Ticket + flights + hotel + domestic ground transport** for speakers. He does not do conferences that skip this. |
| **Air** | He **books own flights**, reimbursed (prefers [Wise](https://wise.com); PayPal OK). Agency booking also fine. |
| **Cabin** | **First class international.** **Business class domestic** (US/Canada). |
| **Recovery** | **~24h after landing** before any conference duty (esp. international). Hotel nights must cover that. |
| **Hotel** | **You book** hotel (bulk rate OK). Near venue. Send confirmation + **calendar invite** for check-in/out with address + conf numbers. |
| **Home ASAP** | Leaves family with four kids — often **skips or shortens after-conference activities**. Don’t build critical programming that requires him late. |
| **Recording** | Expects talk **recorded** and on **YouTube** promptly (their channel or he uploads). **Live stream** preferred (family can watch). |
| **Code of conduct** | Must be **advertised and enforced**. |
| **Calendar** | **Digital calendar invites** for every when/where (tech check, talk, hotel, meals) — don’t only email prose. |
