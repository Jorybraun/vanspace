### Day vs night (Science World)

| | Day (~$3,500) | Night (~$2,500) |
| --- | --- | --- |
| **Fits** | Classic micro-con clock (doors ~morning, talks through afternoon) | After-hours energy, cheaper room |
| **Watch** | Public museum hours / noise / load-in next to visitors | Guest energy after work; F&B/bar rules; end time for SkyTrain |
| **After party** | Possible on-site or nearby | Easier to blend into evening social |
| **Speaker travel** | **Speakers staying overnight** → day block is natural (sleep, full program, evening free / soft social) | Night-only con wastes the hotel night for a short evening block |

**Speakers overnight (locked preference):** Kent / Wes (and other fly-ins) **stay the night** → prefer **day package ($3,500)**.  
Night ($2,500) is not a good primary block if talent is already in town for a full day; use night only if you **add** an evening social after a day program (confirm if day+night stacks $).

**Default lean for VanSpace:** **day package ($3,500)** + hotel for speakers (`budget.md`).

- [ ] Exact hours (in/out), overtime rate

- [ ] Wi‑Fi

**Why it’s winning right now**

- **~$1.5k under** the old Space Centre ~$5k planning band (day)  
- **Night $2,500** is very cheap for a landmark room  
- **Easier to get to** → better show rate, less “where is Vanier Park” friction  
- Still science-branded, not a hotel ballroom  

**Watch-outs**

- Brand story shifts from **saucer / Space Centre** to **dome / Science World** (site + sponsor PDF + Luma)  
- Daytime may share building with public visitors  
- Don’t stack day + night prices unless you’re buying both blocks
